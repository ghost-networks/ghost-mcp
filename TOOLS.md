# Ghost Networks MCP Tools

Generated by `ghost-cli mcp --list-tools` (ghost-cli v0.40.0). 41 tools.

Configure your MCP client:

```json
{"mcpServers":{"ghost":{"command":"ghost-cli","args":["mcp"],"env":{"GHOST_API_KEY":"<your-api-key>"}}}}
```

`tools/list` works without an API key; tool calls need `GHOST_API_KEY` (or a prior `ghost-cli init`).

## ghost_init

Initialize Ghost CLI with an API key. Validates the key, generates crypto keys, and optionally joins a network via helbind key.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `api_key` | string | yes | Ghost Networks API key |
| `helbind_key` | string | no | Path to key.json for automatic network join (optional) |
